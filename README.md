# Road Network Segmentation from Sentinel-2 Satellite Imagery

## 1. Introduction

Road network extraction from satellite and aerial imagery is a fundamental task in remote sensing and geospatial analysis, with applications in:

- Urban planning
- Disaster response
- Military intelligence
- Logistics optimization
- Autonomous navigation systems

Manual digitization of roads from satellite imagery is time-consuming, expensive, and difficult to scale for the large volumes of data generated by modern Earth observation satellites such as :contentReference[oaicite:0]{index=0} Sentinel-2.

Automated road segmentation presents several technical challenges:

- Roads appear in diverse environments including urban, suburban, rural, and forested regions.
- Road widths vary significantly from narrow footpaths to multi-lane highways.
- Spectral signatures overlap with rivers, railways, rooftops, and soil.
- Tree canopies frequently occlude road surfaces.
- Illumination conditions and seasonal changes affect visibility.

This project develops a **semantic segmentation pipeline** that produces **pixel-level binary masks** identifying road pixels in Sentinel-2 multispectral imagery.

The approach leverages the **DeepLabV3+ architecture** with an **EfficientNet-B4 backbone** and atrous convolutions to capture road context at multiple scales, enabling robust segmentation across diverse terrain and road structures.

---

# 2. Problem Statement

Given a **256×256 Sentinel-2 satellite image patch**, the objective is to generate a **binary segmentation mask** of the same dimensions where:

- `1` → Road pixel
- `0` → Non-road pixel

## Key Challenges

### • Class Imbalance
Road pixels occupy only a small fraction of the image, causing models to bias toward background prediction.

### • Scale Variability
Road widths vary significantly:

- Narrow rural tracks: 2–4 pixels
- Urban highways: 15–30+ pixels

### • Contextual Ambiguity
Roads in forested areas are often partially hidden by tree canopy, requiring contextual reasoning.

### • Spectral Similarity
Road surfaces often resemble:

- Rooftops
- Bare soil
- Dry riverbeds

This requires strong spatial understanding rather than relying solely on spectral information.

### • Boundary Precision
Segmentation metrics penalize blurry predictions, making fine-grained boundary recovery essential.

# 4. Dataset

## 4.1 Source

The dataset used is the **ISRO Sentinel-2 Roads Dataset**, consisting of:

- **5,634 image-mask pairs**
- Sentinel-2 Level-2A imagery
- Diverse Indian terrain coverage

Each sample contains:

- A `256×256` RGB image patch
- Corresponding binary road mask

The RGB images are derived from:

- Band 2 → Blue
- Band 3 → Green
- Band 4 → Red

Road masks were manually annotated.

# 5. Model Architecture — DeepLabV3+ with EfficientNet-B4

The segmentation model is based on **DeepLabV3+**, a state-of-the-art encoder-decoder architecture for semantic segmentation.

The architecture consists of three major stages:

---

## Stage 1: Encoder — EfficientNet-B4

The encoder uses **EfficientNet-B4** as the backbone feature extractor.

### Key Features

- Hierarchical feature extraction
- Depthwise separable convolutions
- Multi-scale feature learning
- Compound scaling of:
  - Width
  - Depth
  - Resolution

### Benefits

- Captures fine road edges
- Preserves large-scale contextual structure
- Provides computational efficiency
- Utilizes ImageNet pre-trained weights for transfer learning

---

## Stage 2: Atrous Spatial Pyramid Pooling (ASPP)

The ASPP module serves as the bridge between the encoder and decoder.

It applies parallel dilated convolutions with dilation rates:

- 6
- 12
- 18

This enables multi-scale contextual understanding without reducing spatial resolution.

### Role of Different Dilation Rates

| Dilation Rate | Captures |
|---|---|
| 6 | Narrow rural roads and footpaths |
| 12 | Standard roads |
| 18 | Wide urban highways |

The extracted multi-scale features are concatenated and projected into a rich contextual representation.

---

## Stage 3: Decoder

The decoder combines:

- Low-level encoder features
- High-level ASPP output

through:

- Bilinear upsampling
- Convolutional projection

### Purpose

This stage restores:

- Fine-grained road boundaries
- Spatial details lost during encoder downsampling

### Final Output

The network produces:

- A `256×256` binary segmentation map
- Generated using:
  - `1×1 convolution`
  - `Sigmoid activation`
